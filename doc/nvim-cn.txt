*nvim-cn.txt*	Neovim 中文帮助（本配置专用）		*nvim-中文帮助*

==============================================================================
Neovim 中文帮助索引                                          *nvim-cn-index*
==============================================================================

这是本配置附带的中文帮助页。Neovim 官方只提供英文帮助，本页把**最常用的
内容**整理成中文；完整的英文原版帮助仍然可用，见下方「如何查阅原版帮助」。

内容包括：~
  |cn-start|       入门：打开文件、保存、退出
  |cn-keys|        本配置的键位速查（leader 键为空格）
  |cn-window|      窗口与分屏
  |cn-find|        查找与浏览（Telescope / 文件树）
  |cn-lsp|         代码导航（LSP）
  |cn-plugins|     插件与工具管理（Lazy / Mason）
  |cn-i18n|        界面汉化说明与自查命令
  |cn-tutor|       中文教程
  |cn-help|        如何查阅原版帮助与其它资料

==============================================================================
入门                                                        *cn-start*
==============================================================================

打开文件~
  :e 文件路径              打开文件（支持 Tab 补全）
  :q                       退出当前窗口
  :w                       保存
  :wq 或 :x                保存并退出
  :q!                      放弃修改强制退出
  :qa!                     退出全部窗口（不保存）

在文件树里：`<空格>e` 打开/关闭文件树，`a` 新建文件或目录，`d` 删除，
`r` 重命名，`<CR>` 打开文件，`g?` 查看文件树的全部键位。

==============================================================================
本配置键位速查                                                  *cn-keys*
==============================================================================

leader 键是**空格**。按下空格停约 0.3 秒会弹出 which-key 菜单（已汉化）。

编辑~
  jk                       插入模式下退出插入模式
  gc / gcc                 注释选中内容 / 当前行
  gb / gbc                 块注释
  J / K                    可视模式下选中内容下移 / 上移

窗口见 |cn-window|，查找见 |cn-find|，代码导航见 |cn-lsp|。

窗口与分屏                                                    *cn-window*

  <空格>sv                 垂直分屏（左右）
  <空格>sh                 水平分屏（上下）
  <空格>sc                 关闭当前窗口
  <C-h> <C-j> <C-k> <C-l>  跳到左 / 下 / 上 / 右窗口
  <C-w>h/j/k/l             同上（Neovim 原生方式）
  <C-w>w / <C-w>W          在窗口间循环切换 / 反向循环
  <C-w>s / <C-w>v          水平 / 垂直分屏
  <C-w>c / <C-w>o          关闭当前窗口 / 只保留当前窗口
  <C-w>=                   所有窗口等宽等高
  <C-w>+ / <C-w>-          增加 / 减少高度
  <C-w>> / <C-w><          增加 / 减少宽度
  <C-w>x                   与相邻窗口互换位置
  <C-w>T                   把当前窗口移到新标签页
  <S-L> / <S-H>            下一个 / 上一个缓冲区
  <空格>x                  关闭当前缓冲区

查找与浏览                                                      *cn-find*

  <空格>ff                 查找文件（Telescope）
  <空格>fr                 最近打开的文件
  <空格>fg                 全局搜索内容（需 ripgrep）
  <空格>fb                 切换缓冲区列表
  <空格>fh                 搜索帮助文档
  <空格>e                  开关文件树（nvim-tree）
  <空格>a                  开关代码大纲（aerial）
  <空格>nh                 取消搜索高亮
  <空格>d                  回到启动页

在 Telescope 里按 `<C-/>` 会弹出键位表（已汉化）。

代码导航（LSP）                                                  *cn-lsp*

  gd                       跳转到定义
  grn                      重命名符号
  gra                      代码操作（快速修复）
  grr                      列出所有引用
  gri                      跳转到实现
  grt                      跳转到类型定义
  gO                       列出当前文件符号
  ]d / [d                  下一个 / 上一个诊断
  ]q / [q                  下一个 / 上一个 quickfix 项

插件与工具管理                                              *cn-plugins*

  <空格>ll                 打开插件管理（:Lazy）
  <空格>lm                 LSP 与工具管理（:Mason）
  :Lazy profile            查看启动耗时分析
  :Mason                   打开 Mason 主界面，`g?` 看帮助
  Alt+p                    开关浮动终端
  <空格>mt                 开关 Markdown 渲染

其它常用命令~
  :Lazy restore            按 lazy-lock.json 回退全部插件版本
  :TSUpdate                重新编译语法解析器
  :checkhealth             健康检查（常用部分已汉化）

==============================================================================
界面汉化说明与自查                                              *cn-i18n*
==============================================================================

本配置的界面汉化由 `lua/core/i18n/` 下的模块实现，启动后 1.5 秒自动执行。
三个自查命令~

  :I18nPatch               立即重新执行汉化（正常显示改写 0 个文件）
  :I18nRules               列出全部汉化规则与目标文件（!! 表示目标不存在）
  :I18nAudit               扫描插件里剩余的英文界面文本

汉化日志：`stdpath("state")/i18n.log`（每次改写了哪些文件都记在里面）。

**做不到的部分**：Neovim 本体的错误消息在编译期就写死在 nvim.exe 里，官方
Windows 构建没有链接 libintl，放语言包也不生效 —— 所以 E/W 系列消息只能用
正则逐条翻译（本配置已覆盖官方 191 条消息 + 高频组合消息）。

中文教程                                                        *cn-tutor*

Neovim 自带官方中文教程，直接打开：

  :Tutor zh/vim-01-beginner

如何查阅原版帮助                                                *cn-help*

  :help                    原版帮助首页（英文）
  :help <主题>             例如 `:help options`、`:help lua-guide`
  :help <命令>             例如 `:help :Lazy`、`:help :Mason`
  :helptags <目录>         为新增的帮助文档生成 tags 索引

 > 说明：`'helplang'` 已设为 `cn,en`，所以只要某个主题存在中文页
 > （如本页 `doc/nvim-cn.txt`）就会优先显示中文，否则自动回退英文原版。
